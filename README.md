# Gym Routine Mobile Web

Aplicación web ligera en modo oscuro para iPhone (y otros móviles) que permite gestionar la rutina del gimnasio por días de la semana. Cada día se pueden agregar ejercicios indicando repeticiones y peso, los cuales se almacenan en `localStorage`.

## Uso

1. Abrir `index.html` en el navegador del móvil.
2. Cambiar de día usando los botones en la parte superior.
3. Completar el formulario para agregar un nuevo ejercicio a ese día.
4. Los datos quedan guardados en el dispositivo.
